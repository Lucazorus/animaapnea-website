Die Vorbereitungsatmung: so bereiten Sie eine statische Apnoe vor

Die zwei oder drei Minuten vor einer Apnoe prägen alles, was danach kommt. Richtig gemacht, lässt die Vorbereitungsatmung Sie ruhig, schwer und bereit zurück. Falsch gemacht, wird sie zur versteckten Hyperventilation. So machen Sie es richtig.
