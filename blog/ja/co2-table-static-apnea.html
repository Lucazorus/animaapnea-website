CO₂テーブル完全ガイド：「息がしたい」を先へ延ばすために

ほとんどの息止めを終わらせているのは、酸素不足ではなく二酸化炭素です。CO₂テーブルがまさにその限界をどう鍛えるのか、自分用のテーブルをどう組むのか、そしてリスクを冒さずにどう伸ばしていくのかを解説します。

LM Lucas MassoniAnima Apnea 創設者 ·2026年10月12日更新 ·読了時間12分

この記事のポイント

  • 息がしたいという衝動を生むのはCO₂の上昇です。酸素が危険な水準になるよりずっと前に起こります。
  • CO₂テーブルではホールド時間を固定（自己ベストの約50%）し、ラウンドごとにリカバリーを短くしていきます。
  • 基本形は8ラウンド、リカバリーを1ラウンドごとに15秒短縮、週2〜3回。
  • ひとりで練習するときは必ず陸上で。過呼吸は厳禁、水中でひとりは絶対にだめです。

フリーダイバーなら誰もが知っている瞬間があります。ホールドの最初のうちは楽で、むしろ心地よいくらいです。やがて喉が詰まるような感覚が出てきて、「空気が欲しい」という小さな声が聞こえ始め、横隔膜が勝手にぴくぴくと動き出します。多くの初心者はそこで止めてしまいます。酸素が切れかけていると思い込むからです。しかし実際には、その時点での酸素飽和度はまだ高いままです。

この警報の正体は二酸化炭素です。そしてCO₂テーブルが教えてくれるのは、まさにそれへの対処法、つまりCO₂が上がっていくなかで落ち着いて力を抜いていられる力です。このガイドでは、その仕組みを説明したうえで、計算ツールを使ったわかりやすいテーブルの組み方を紹介し、典型的なセッションの流れと数週間にわたる進め方を順に見ていきます。

息止めを止めさせるのはCO₂

息を止めている間も、体は酸素を消費し、CO₂を作り続けています。呼吸で排出できないCO₂は血液中にたまり、炭酸となってpHを下げます。脳幹と頸動脈にある化学受容器と呼ばれる専用のセンサーがこの酸性化を感知し、「呼吸せよ」という指令を出します。

研究では、スタティックアプネアの息止めは2つのフェーズに分けて説明されています1。まず、目立った不快感のないイージーフェーズ。そして生理的限界点、つまり横隔膜の最初の不随意収縮を境にストラグルフェーズが始まり、コントラクションが繰り返し、次第に強くなっていきます。トレーニングを積んだフリーダイバーでは、この第2フェーズがホールド全体のかなりの割合を占めることがあります2。

複数の研究により、トップレベルの息止めダイバーは、ダイビングをしない人に比べてCO₂に対する換気応答が鈍いことが示されています2。この耐性の一部は生理的なものですが、一部は明らかに学習によるものです。コントラクションは危険信号ではないと知っていること、そしてそれが過ぎ去るまで力を抜いていられること。コントラクションにはむしろ役に立つ面もあり、一時的に脳への血流と酸素供給を改善します3。

CO₂テーブルで酸素が増えるわけではありません。CO₂が扉を叩いてきても慌てない方法を教えてくれるのです。

CO₂テーブルとは何か

CO₂テーブルとは、ホールド時間を一定に保ったまま、ラウンドごとにホールド間のリカバリーを短くしていく一連の息止めのことです。たまったCO₂を排出する時間がだんだん短くなるため、各ホールドは前のホールドよりも少し多くのCO₂を抱えた状態で始まります。コントラクションが早く訪れるようになり、それこそがトレーニング刺激になります。

O₂テーブルはその逆で、リカバリーを一定にしてホールドを長くしていきます。低酸素への耐性を鍛え、自分の最大値に近づいていくトレーニングです。両者は補い合う関係にありますが、始めるならCO₂テーブルが適しています。ホールドが限界から十分に離れているからです。どちらを選ぶべきか迷ったら、2つのテーブルの比較記事を参考にしてください。

4つのルールでテーブルを組む

すべての出発点は、陸上でのスタティックの自己ベストです。最近、良いコンディションで測ったものを使ってください。わからない場合は、まず測定しましょう。横になり、数分間落ち着いて呼吸してから行います。

  1. 固定ホールド：自己ベストの約50%自己ベストが3:00なら、すべてのホールドを1:30にします。15秒単位で丸めてください。
  2. 最初のリカバリー：自己ベストの約3分の2自己ベストが3:00なら、リカバリー2:00から始めます。第1ラウンドで2:00を下回らないようにしてください。
  3. 短縮幅：1ラウンドごとに15秒これが標準的な刻みです。CO₂を少しずつ高めつつ、セッションの終盤がサバイバルテストにならずに済みます。
  4. 8ラウンド1回のセッションは20〜25分ほどになります。最後のほうが厳しすぎるなら6ラウンドから始めましょう。

良いセッションの進め方

テーブルそのものは仕事の半分にすぎません。ホールドの合間とホールド中に、どう呼吸し、どう緊張を手放すかで、結果はまったく変わります。

  1. 陸上で横になる静かな部屋のベッドやソファで。スマートフォンはタイマー以外を機内モードにしておきます。
  2. 2〜3分、落ち着いた呼吸ゆっくりとした腹式呼吸で、吐く息を吸う息より長くします。大きな呼吸を何度も繰り返すのはやめましょう。何かを「チャージ」しようとしているわけではありません。
  3. 深く、でも無理のない吸気を1回お腹、次に胸を満たし、肺活量の85〜90%ほどまで吸います。無理に吸うと緊張が生まれ、緊張は酸素を消費します。
  4. ホールド中：意識的なリラックスあごから足先まで体をスキャンしていきます。コントラクションが来たら、抵抗せずに通り過ぎさせましょう。それは波であって、危険信号ではありません。
  5. 終了後：リカバリーブリージング息をわずかに吐き、素早く深く吸い込んで、軽く圧をかけたまま1〜2秒止める。これを2〜3回繰り返します。リカバリーの間はずっと横になったままでいてください。
✓
コントラクションを数える

最初のコントラクションが来るタイミングは、CO₂耐性の向上を示す最良の指標のひとつです。同じテーブルで、それが週を追うごとに遅くなっているなら、自己ベストがまだ変わっていなくても確実に上達しています。

頻度と数週間の進め方

適応が起こるのはセッション中ではなく、回復している間です。毎日テーブルをこなしても疲労が積み重なるだけで、上達が早まることはありません。CO₂セッション同士の間を最低48時間空けた、典型的な1週間を紹介します。

テーブルの効果を損なう5つの間違い

  • ホールド前の過呼吸。速く激しい呼吸はCO₂を人為的に下げます。呼吸衝動は遅れてやってきますが、酸素はほとんど増えません。予備を増やさないまま警報だけを切ってしまう、ブラックアウトの典型的なパターンです4。
  • 設定が高すぎる。自己ベストの70%のホールドでは、CO₂テーブルが持久力の苦行になってしまいます。50%前後にとどめましょう。
  • コントラクション中に力む。あごや拳を握りしめると酸素を消費し、不快感も強まります。
  • リカバリーをおろそかにする。終盤のリカバリーは短いので、一呼吸一呼吸が大切です。リカバリーブリージングを使いましょう。
  • 毎日トレーニングする。多ければよいわけではありません。質の高い2〜3回は、雑な7回に勝ります。

絶対に守るべき安全ルール

!
水中でひとりで息止めの練習をしてはいけません

低酸素によるブラックアウトは、まったく前触れなく起こることがあります。水中では、それが一瞬で命取りになりかねません。ひとりでのテーブルは陸上で、横になって行う。例外はありません。水中で行うのは、訓練を受けたバディが最初から最後まで見守っている場合だけです。

  • ホールド前に過呼吸をしないこと。
  • めまい、手や唇のしびれ、視覚の異常、そのほかいつもと違う感覚があれば、セッションを中止してください。
  • ホールドを途中でやめるのは失敗ではありません。1:30の予定を1:20で切り上げるのも、賢いトレーニングのうちです。
  • 運転中、入浴中、立ったまま、そのほか意識を失うと危険な場所では絶対に行わないでください。
  • 心臓や肺の疾患、てんかんがある場合や妊娠中の場合は、医師に相談してください。

よくある質問

CO₂テーブルは週に何回行えばよいですか？

週2〜3回、セッションの間を最低48時間空けてください。それ以上増やしても疲労がたまるだけで、効果は上がりません。

CO₂テーブルは陸上と水中のどちらで行うべきですか？

ひとりで練習するときは必ず陸上で、ベッドやソファに横になって行います。水中で行うのは、訓練を受けたバディが最初から最後まで見守っている場合に限ります。

途中のホールドを最後までこなせなかったら？

そのホールドは終えて呼吸し、体調に問題がなければテーブルを最後まで続けます。最初のほうのラウンドで起きた場合は、次回のセッションでホールド時間を15秒短くしてください。

効果を感じるまでどのくらいかかりますか？

定期的に続ければ、多くの人が2〜4週間ほどで楽になったと感じます。コントラクションが始まるのが遅くなり、受け流しやすくなります。最大息止め時間の伸びには大きな個人差があります。
